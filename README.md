# Spacewar

Canvas 射擊遊戲，搭配即時 3D 模組化主角機與 A2.2 風格的像素敵機。

## 執行

```sh
npm install
npm start
```

開啟 http://127.0.0.1:1234。`npm run build` 產生正式版本，`npm test` 執行測試。

## 操作

- 方向鍵移動；按住 Space 連射並展開攻擊型態，放開後收合。
- A：音爆後向各方向發射多波隨機短雷射。
- S：空氣盾，會迎向來彈，耗盡後可重新施放。
- P / Esc 暫停，R 重新出擊。
- 手機觸控：拖曳移動並自動射擊；畫圈後放開施放防護盾；雙擊施放攻擊波。技能卡也可直接點擊。

畫圈支援約四分之三圈以上的開口圓、橢圓與略微抖動的軌跡，也能在持續拖曳後辨識最後畫出的圓。小圈與較慢的圈都有較寬容的尺寸、時間與收尾容錯；一般直線拖曳、U 形轉彎與小幅手指抖動不會視為施盾手勢。

## 美術與效能

主角機由 Three.js 實際繪製低面數模型，再合成到遊戲畫布；具有普通／攻擊型態的連續折臂動畫，以及移動時的傾斜。機身主色為 `#FFFFFF`，側面為淡灰色。火砲最大展開幅度限制在原示範的 57%，砲管仍完整伸出。遊戲版為 1,136 個三角形、40 個材質批次，使用簡化光照、不產生陰影貼圖，共用一個繪製器。姿態與型態不變時重用渲染結果。

中央短尾主推進器與半尺寸輔助推進器已實裝：向前啟動主推進器；向右時左輔助推進器下放並啟動，向左則反之。左右操控會讓機身側傾、機鼻小幅轉向，前後操控會俯仰；按住時保持姿態，鬆開平順回正。鍵盤姿態依操控方向判定，觸控依拖曳位移判定；斜向可同時作動。減少動態效果偏好會取消機身傾斜。

後退時左右輔助推進器分別向外旋轉 180°、朝機頭噴射；中央主推進器保持關閉。尾焰由 3D 噴嘴位置與朝向投影到遊戲畫布，隨機身姿態和輔助推進器關節對齊。白／淡黃小方點粒子只從中央主推進器尾端排出，每次新航程重設，總量有上限。

防護盾只在半徑 11 格（護盾半徑的 2.2 倍）內感應敵彈與敵機。敵機碰到盾片會受到一次普通傷害並消耗一片盾，同一敵機有 8 個更新幀的接觸間隔。

敵機使用 `img/enemies/` 的 A2.2 圖片，保留紫灰裝甲、桃紅標記與橘色核心。一般敵機最長邊 96px，大型 Boss 為 160px；受擊遮罩只建立一次。環形 Boss 的節點沿實際碰撞位置排列。

## 劇本與 Boss

主線沿用原本戰機、射擊、攻擊波、粒子空氣盾與觸控手勢。里程以固定 40 Hz 推進，Boss 戰會停留，整組擊破才繼續；停留中的事件只執行一次。

| 里程 | 段落 |
| --- | --- |
| 0–1199 | 初航巡邏、交叉火網，逐步加入強化敵機與砲台 |
| 1200 / 1500 | 戰前修復，雙環封鎖戰 |
| 1501–2039 | 三連射與一次永久機體升級，升級火力實戰 |
| 2040 / 2200 | 停止增援、修復，求生怪獸單體決戰 |
| 2201–2679 | 12 秒無新增敵群的喘息與修復 |
| 2680–4079 | 重返航線、突破封鎖，逐步加密敵群 |
| 4080 / 4240 | 修復後進入有護航敵群的雙環反擊戰 |
| 4241–5279 | 戰後整備、巨獸前線與雙獸戰前準備 |
| 5280 | 兩隻舊哥吉拉聯手，各 400 生命，整組擊破才推進 |
| 5281–5599 | 8 秒返航整備與修復 |
| 5600 起 | 無盡航行，6240、7040 逐步提高密度 |

新怪獸使用 **JJJ（Caseys42）／MMDCharizard** 的修改減面模型：1,536 個三角形、125 骨骼，保留較細緻的臉部、眼睛與下顎；灰色背面與藍色下腹、下顎及尾部。骨盆、兩節軀幹、兩節頸部、頭部與十五節尾骨共 21 個加權關節，具有步態波、逐節轉向延遲與急停回擺；固定邏輯更新，繪圖不推進動作。嘴巴平常閉合，蓄熱與射線時張開。碰撞輪廓與嘴部發射點跟隨實際骨架姿勢。

牠以肉搏、側切、假衝與假撤退求生；最近 8 秒實際承傷達 48 且仍受威脅，才進入預警、蓄熱、熱射線與衰弱撤離，射線冷卻 16 秒。肉搏與射線都使用原本受傷流程，粒子盾沿用既有攔截判定。

兩隻舊哥吉拉保留原本 **564 面的抽象 3D 模型**、分路包抄、九格間距與防穿越導航、隨機蓄力爆衝，以及原本先慢後快的 270° 熱射線。舊雙 Boss 與新怪獸是分開的主線遭遇戰。

[完整 demo](https://yecapee.github.io/spacewar/dist/) · [直接挑戰新怪獸](https://yecapee.github.io/spacewar/dist/?encounter=kaiju) · [兩隻舊哥吉拉聯手](https://yecapee.github.io/spacewar/dist/?encounter=kaiju&wave=multi)。快捷入口不更新一般生存模式紀錄。

模型來源、作者規則與公開 demo 的授權確認記錄見 [模型說明](art-prototypes/zilla-jjj/README.md) 及 [source.json](art-prototypes/zilla-jjj/source.json)。正式包只含已確認可用於本 demo 的修改減面模型，不包含原始下載包、高面數原模型、帳號或個人附件。僅作非商業展示，請勿把本專案的使用許可當作任意再散布模型的授權。

`npm run build` 從原遊戲入口建立 classic JS 正式包，並將模型、報告及作者標示放入 `dist/assets/creature/`；建置完成後才替換 `dist/`。GitHub Pages 沿用 `master` 分支的 `/dist/` demo。

獨立怪獸控制器與關節參數保留在 `art-prototypes/zilla-combat/`，不建立另一套玩家或戰鬥系統。

`art-prototypes/modular-interceptor/` 保留原始設計與 GLB。遊戲模型共用該幾何工廠，以低細節選項移除倒角與微小零件，再依動畫關節合併材質。模型預算與折臂運動由 `tests/shipModel.test.mjs` 檢查。

`art-prototypes/enemy-a22/` 保留敵機圖集與提示詞。`art-prototypes/fleet-preview.html` 可透過專案根目錄的靜態伺服器檢視整支機隊：

```sh
python3 -m http.server 8768 --bind 127.0.0.1
```

開啟 http://127.0.0.1:8768/art-prototypes/fleet-preview.html（先執行 `npm install`）。

預覽頁與遊戲共用機體、折臂與推進器設計。頁面含四組即時配色盤與自訂機身主色，選擇儲存在該預覽頁的 localStorage，重新整理後保留；遊戲使用固定的 `#FFFFFF` 主色。

## 引擎效能

更新與繪製已分離：維持固定 40Hz 遊戲邏輯，畫面按螢幕刷新並插值位置。碰撞使用空間網格與共用形狀快取，子彈／粒子採回收池，普通彈光暈預先快取，HUD 只在變動時寫入，紀錄每秒批次儲存。

`npm run benchmark` 可重跑固定場景壓測。實作細節、測量範圍與限制見 [PERFORMANCE.md](PERFORMANCE.md)。
