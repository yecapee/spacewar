# A2.2 敵方機隊

使用內建 imagegen 製作，參考本次對話選定的 A2.2 設定。保留紫灰裝甲、桃紅標記與橘色核心，包含 Zark Zero、Zark Plus、Fort、Turret、環形 Boss 的單一節點，以及 Gozilla Boss。

`source.png` 是透明背景原始圖集。`prepare.cjs` 只負責分格、裁切與最近鄰縮小，不重新繪畫或生成圖像；輸出放在 `img/enemies/a22-*.png`。一般敵機最長邊 96px，Boss 160px。執行腳本需要 `pngjs` 7，可另外安裝到工具資料夾，設定 `SPACEWAR_PNG_ROOT` 指向該套件。

## 圖集提示詞（內建 imagegen）

Use case: stylized-concept. Asset type: production game sprite atlas, one coherent sprite sheet for Spacewar. Reference image role: A2.2 enemy style and identity only; omit the red player spaceship, labels, frames, background. Create a TRANSPARENT BACKGROUND atlas in a precisely aligned 3 columns by 2 rows grid, six equally sized cells. Each sprite centered in its cell and fits within 72% cell width and 72% cell height with generous transparent separation. Top row left-to-right: ZARK ZERO compact purple-gray drone with two square shoulder pods and one central orange core, nose facing DOWN; ZARK PLUS wide swept-wing purple-gray drone with hot pink wing tips and twin orange glowing cores, nose facing DOWN; FORT heavy oval armored drone with flanking purple-gray shield plates and central orange barrel facing DOWN. Bottom row left-to-right: TURRET four diagonal arms with violet armor pods, pink slits, central orange square reactor, symmetric top-down; ORBIT NODE one single compact small violet armored drone with orange central eye and hot pink stripe, top-down, NOT a whole ring; GOZILLA mechanical kaiju boss, recognizable side-view head faces LEFT, crouched purple-gray plated body, hot pink dorsal spines, ivory claws, open orange glowing mouth, orange reactor in shoulder. Style is the reference refined but economical PIXEL ART with deliberate crisp square pixel clusters, about 64x64 logical pixels per small enemy and 128x128 for kaiju, clean stepped silhouettes, 3-4 shades per material, dark navy outline, readable dark recessed machinery, pale lavender edge highlights, hard purple plates, no crystal theme, no smooth vector shading, no blur, no ground shadows. No text, no labels, no boxes, no separators, no UI, no player ship, no watermark. Preserve real alpha transparency everywhere outside each isolated sprite. All six sprites should be fully visible separated, no overlap. Identical overhead game lighting from upper left.

## 透明邊緣整理提示詞（內建 imagegen）

Use case: background-extraction. Edit target: the attached six-enemy game sprite atlas. Remove the entire black/purple cloudy background and ALL ambient halos, haze, ground shadows, gradients outside the sprites. Output actual ALPHA TRANSPARENCY everywhere outside the six isolated sprite silhouettes. Keep the six sprite designs, colors, pixel art, 3x2 layout and positions unchanged. Maintain dark navy silhouette outlines and bright orange/pink in-sprite details. No glows bleeding outside the edges. The result must be a clean game sprite sheet that can be composited over any background without rectangular dark tiles. No other changes.
