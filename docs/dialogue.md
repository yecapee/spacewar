# A 版首次登場對白

正式入口：`dist/index.html`。採鋼框藍窗、繁體點陣字與清晰的原創賽璐璐頭像。敵方在頂部，我方駕駛員在底部。所有敵人仍由原本的 `js/script.js` 與 `createEnemy` 生成，未建立另一套戰鬥引擎。

## 觸發範圍

| 對話 | 實際生成識別 | 原劇本首次里程 |
| --- | --- | --- |
| 初航巡邏 | zark-zero | 0 起的首次生成 |
| 交叉火網 | fort | 640 起的首次生成 |

里程為劇本鍵值，非秒。一般敵機必須實際生成才觸發；雙環／雙獸需兩個個體均生成才合併演出。共 7 段對白、9 個敵方個體與 1 位我方駕駛員。新舊怪獸不再以共用的 GOZILLA 名稱判斷初見。

同航程只播一次，包含略過；4240 的雙環再戰不重播。重新出擊清空登場紀錄。怪獸以吼聲與動作表意，駕駛員回應牠的意圖。

## 時間與操作

生成後、戰鬥更新前進入 dialogue 階段，暫停敵人、敵彈、技能、碰撞、效果及劇本時計。結束後重設固定步進時計，不補跑閱讀時間。清除按住的方向、射擊與觸控，避免關閉對話時誤發招式。

按任意一般按鍵或點擊畫面任意位置：先補完整句，再前進，最後一句後開始交戰。移除自動、紀錄、略過與繼續的操作列。按住按鍵不會連續跳句；結束對白的輸入會被消耗，A／S 不會施放技能、R 不會重開、Space 不會連射。保留瀏覽器快捷鍵與修飾鍵，避免快捷鍵組合造成連跳。視窗失焦或切至背景會暫停閱讀，返回後按鍵或點擊接續。

使用原生 modal dialog 隔離戰鬥操作，結束後將焦點交回遊戲畫布。對白包含完整台詞的螢幕閱讀器公告；偏好減少動態效果時直接顯示整句。

## 驗證紀錄

- `npm test`：139 項全過，包含任意按鍵推進／長按不連跳／關閉輸入不觸發戰鬥，以及初見去重、雙個體完整生成、同一 tick 的多段排隊、閱讀暫停／歷史／自動、重設與原 session 凍結／恢復測試。
- 原 session 控制器的整段劇本測試跑到里程 7041，七段對白各一次，九個個體皆記錄，雙環再戰不重播。測試以代用敵人物件與自動結束 Boss 驗證流程，並非遊戲難度或實際玩家通關測試。
- 瀏覽器：主遊戲首次 ZARK、求生獵手捷徑、舊雙獸捷徑；任意鍵與點擊推進、讀完後恢復戰鬥、原有暫停及護盾操作正常。新怪獸與雙獸保持在 2200／5280；一般敵機閱讀期間停在 0020，生命保持 5／5。
- 390×844 手機版：上方敵人、下方駕駛與操作鈕皆可見，無橫向溢出；兩張頭像載入成功且 image-rendering 為 auto。原生畫面未以像素方式降低頭像解析度。修正輔助公告文字造成的 17px 焦點捲動後，連續推進時對話根容器 scrollTop 為 0，頂部標題維持在 12px。
- `npm run build`：正式 classic bundle、自有像素字型與十張頭像均打包，保留先前獨立提案頁。

字型採隨附 OFL 的 Fusion Pixel；授權保留於 `art-prototypes/dialogue-proposals/pixel/fonts/` 與公開提案頁。
