# A 版首次登場對白

正式入口：`dist/index.html`。採鋼框藍窗、繁體點陣字與清晰的原創賽璐璐頭像。敵方在頂部，我方駕駛員在底部。所有敵人仍由原本的 `js/script.js` 與 `createEnemy` 生成，未建立另一套戰鬥引擎。

同航程只播一次，包含略過；4240 的雙環再戰不重播。重新出擊清空登場紀錄。怪獸以吼聲與動作表意，駕駛員回應牠的意圖。

## 時間與操作

生成後、戰鬥更新前進入 dialogue 階段，暫停敵人、敵彈、技能、碰撞、效果及劇本時計。結束後重設固定步進時計，不補跑閱讀時間。清除按住的方向、射擊與觸控，避免關閉對話時誤發招式。

Space／Enter／繼續按鈕：先補完整句，再前進。自動模式等待逐字完成與閱讀時間；最後一行結束後開始交戰。另有略過與紀錄。P／Esc 可暫停閱讀；視窗失焦或切至背景也暫停閱讀，返回後以繼續按鈕接續。閱讀紀錄時停止對白計時。

使用原生 modal dialog 隔離戰鬥操作，結束後將焦點交回遊戲畫布。對白包含完整台詞的螢幕閱讀器公告；偏好減少動態效果時直接顯示整句。
